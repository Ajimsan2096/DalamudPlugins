# DalamudPlugins

Plugins de Dalamud para FFXIV.

## Instalación

1. `/xlsettings` → **Experimental** → **Custom Plugin Repositories**.
2. Añade esta URL y guarda:

   ```
   https://raw.githubusercontent.com/Ajimsan2096/DalamudPlugins/main/repo.json
   ```
3. Instala desde `/xlplugins`.

## Plugins

- **LinguaBridge** — traducción de chat en tiempo real entre inglés, francés, español, alemán, italiano, portugués, neerlandés, japonés y ruso. Interfaz en inglés, japonés, alemán y francés (los idiomas del cliente global de FFXIV).
  - `/lb clip` (o el modo *Translate only* de la ventana `/lb`): traduce lo que hayas copiado y copia la traducción, sin enviar nada. Útil para ChocoChat y Velvet de Aetherphone, Discord, webs...
  - **Tutorial guiado** dentro del juego: burbujas que resaltan cada parte de la ventana `/lb` y de los ajustes (`/lb tour`, `/lb tour settings`), y consejos breves la primera vez que usas una función. Se puede saltar en cualquier momento o desactivar por completo (*Settings > Help* o `/lb tips off`).
  - Compatible con **Linkpearl** de Aetherphone: las traducciones aparecen allí también, y `/tr /p ...` o `/tr /t Nombre@Mundo ...` funcionan desde su compositor. Si ocultas canales del chat del juego en Linkpearl, activa *Chat > Translate messages other plugins hid from the chat log*.
