# DalamudPlugins

Plugins de Dalamud para FFXIV.

## Instalación

1. `/xlsettings` → **Experimental** → **Custom Plugin Repositories**.
2. Añade esta URL y guarda:

   ```
   https://raw.githubusercontent.com/Ajimsan2096/DalamudPlugins/main/repo.json
   ```
3. Instala desde `/xlplugins`.

## Plugins

- **LinguaBridge** — traducción de chat en tiempo real.
